One picture of Thursday 19 November 2026, drawn as a newspaper front page: Trump, Xi and Putin meet in Shenzhen at the first-ever trilateral summit on the APEC sidelines; GTA VI launches worldwide after a 13-year wait; Iran widens its strikes to US bases in Kuwait; Anthropic lists on the Nasdaq as ANT in the biggest IPO ever; and a Van Gogh with a Nazi-era past sells for a record $190.4M.

`main.ts` draws the whole 1024×1024 poster when it runs — a hand-written PNG writer, a 5×7 pixel alphabet, and five small scenes, all in code. It needs Node 22 and nothing else: no downloaded images, no network, and the same bytes every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

That writes `out/entry.png` (1024×1024, well under 1 MiB). Run it twice and the two files are byte-identical.
